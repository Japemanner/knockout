# Tooling — Hypotheses (onvoldoende data om te bevestigen)

- **H1 — Twee gelijktijdige opencode-sessies in één werkmap doorbreken elkaars state**: de werkmap heeft één checkout; branch-switches (via speckit create-new-feature of handmatig) gelden voor álle sessies, en shared state (`specify/feature.json`, AGENTS.md-speckit-marker, specs/-bestanden) wordt overschreven door de laatst schrijvende sessie. Geconstateerd 2× op 2026-10-14 tijdens feature 023: (1) een parallelle 024-setup switchte de branch naar 024-post-bijlagen en her-richtte feature.json + AGENTS-marker; (2) een parallelle 023-takenrun overschreef `specs/023-content-kalender/tasks.md` met eigen naamgeving en voegde `contracts/ui-components.md` toe. Bevestigingen: 2. Bij 3+ promotie-overweging: rule "één actieve sessie per werkmap; feature-switch alleen na checkpoint". Mitigatie die werkte: selectief stagen bij commit + verzoeningsnotitie in de feature-docs.
- **H2 — Selectief stagen beschermt parallel werk bij conflict**: door expliciet `git add <paden>` te gebruiken i.p.v. `git add .` bleef het werk van de parallelle sessie (specs/024-post-bijlagen/) onaangeroerd en werd de eigen feature-commit zuiver. Bevestigingen: 1.
